# Vue Product Showcase

A polished Vue 3 storefront landing page with a hero section, category highlights, and a responsive product grid.

## Features

- Responsive navigation and hero banner
- Curated product cards with pricing and reviews
- Modern styling using Vue + Vite + Tailwind CSS
- Ready-to-use production build and lint checks

## Getting started

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

## Lint and format checks

```sh
npm run lint
```
